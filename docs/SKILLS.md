# Installed Agent Skills (Curated 16 Skills)

This document catalogs the 16 curated skills installed in `.agents/skills/` for the Satark project:

1. **andrej-karpathy**: Behavioral guidelines to reduce LLM coding mistakes, make surgical changes, surface assumptions, and define verifiable criteria.
2. **anti-ui-slop**: Prevents generic AI UI, enforces rich design systems, covers required states, and verifies visual rendering.
3. **before-you-build**: Assesses product risk, demand, alternatives, and failure signals before coding.
4. **brainstorming**: Disciplined reasoning for architectural choices and feature validation.
5. **break-ai-fix-loops**: Breaks ineffective repair loops with stable fingerprints, a 3-attempt budget, and rollback.
6. **browser-testing-with-devtools**: Live DOM, accessibility, console, network, and layout validation in Chrome.
7. **deterministic-design**: Mathematical and layout balance audits (optical center, spacing, contrast) and heuristic usability.
8. **emil-design-eng**: High-craft animation, spring physics, and micro-interactions inspired by Emil Kowalski.
9. **falsify**: Scientific hypothesis testing and failure-seeking for high-stakes cybersecurity and ML decisions.
10. **frontend-lighthouse**: Core Web Vitals CI budgeting, performance, and accessibility auditing.
11. **gemini-api-dev**: Official Google GenAI SDK patterns for structured JSON threat analysis and multimodal input.
12. **mock-hunter**: Audits live UI to verify real vs mock data, classify endpoints, and prevent placeholder metrics.
13. **production-audit**: Comprehensive production readiness review across security, secrets, API leaks, and headers.
14. **react-best-practices**: Vercel engineering performance guidelines for Next.js App Router and React Server/Client components.
15. **skill-security-audit**: Pre-installation and dependency auditing to prevent credential leaks or unsafe code execution.
16. **systematic-debugging**: Root cause analysis and step-by-step verification before applying fixes.

**Total skills count**: 16 (within the 16-skill cap)
